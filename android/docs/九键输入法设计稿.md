# 九键输入法（TV T9 面板）详细设计稿

> 版本 **v1.2** · 2026-11-22 · 隶属 murmur-ime（MurmurImeService）的**可选键盘面板模式**
> v1.2 变更：**数字模式定为直通模式**——无候选直接上屏，左右键经 InputConnection 移动输入框光标（不透传 KeyEvent，防焦点跳出），上下键不透传
> v1.1 变更：右侧新增**按键预览区**（数字串 + 预测拼音/字母组合，可选中）；默认焦点改在候选区；上键进入拼音区；翻页并入左右环绕；补交互遗漏修复（光标移动、EditorAction、密码遮蔽、composing 内联、唤起双路径等）
> 硬件基准：TX6 / Android 9 / WNF171 蓝牙遥控器（数字键 0-9、方向键、OK、返回、MENU）

---

## 1. 定位与总原则

1. **可选模式**：九键面板是 murmur-ime 的第二形态。设置页「键盘面板：关闭（纯语音）/ 九键」，默认**关闭**，不影响现有纯语音输入场景（1dp 透明窗口行为保持）。
2. **同一 IME 双能力**：面板显隐不影响语音输入与 `commitText` 上屏链路；九键只是新增"文字输入来源"。
3. **TV 单焦点模型**：全部操作仅用遥控器。焦点在「键盘区 / 候选区（词）/ 拼音区（组合）」三层之间切换。
4. **焦点判定复用** `FocusPolicy`：`inputType == TYPE_NULL` 视为无输入框，不弹面板、不消费按键。

## 2. 整体布局（1920×1080 横屏）

```
┌──────────────────────────────────────────────────────────────┐
│                （输入框所在应用界面，adjustResize 顶起）          │
├────────────────────┬─────────────────────────────────────────┤
│  左侧键盘区（38%）   │  右侧候选区（62%），自上而下：              │
│  3 列 × 4 行 12 键   │  ① 按键预览区                             │
│  [1] [2ABC] [3DEF]  │     数字串（灰）+ 预测组合行（可选中，高亮）   │
│  [4] [5JKL] [6MNO]  │  ② 词候选行（默认焦点层，←→ 选词环绕翻页）    │
│  [7] [8TUV] [9WXYZ] │  ③ 页码行：第 x/y 页 · 操作提示            │
│  [#] [0空格] [删除]  │  ④ 预览条：输入框已上屏尾部 20 字           │
└────────────────────┴─────────────────────────────────────────┘
```

- 面板高度 **420px** 贴底浮动，顶角圆角 16px；键盘区/候选区间隔 24px。
- 打开时焦点：**键盘区 [5]**（尚无输入）。每次按键产生候选后，焦点**自动落在词候选行第 1 格**（用户规格：默认选中候选区）。
- composing 同步策略：九键按键序列用 `setComposingText()` **内联显示在输入框**（Android 标准，下划线样式）；上屏用 `finishComposingText` 语义（先设置最终词再提交，避免闪断）。

## 3. 左侧键盘区（12 键）

### 3.1 基础布局

| 行 | | | |
|---|---|---|---|
| 1 | **1** | **2** | **3** |
| 2 | **4** | **5** | **6** |
| 3 | **7** | **8** | **9** |
| 4 | **#** | **0** | **删除** |

### 3.2 键帽随模式变化

| 键 | 数字模式 | 拼音模式 | 英文（小写态） | 英文（大写态，按 1 后） |
|---|---|---|---|---|
| 1-9 | 纯数字大字（无角标） | 数字 + **大写字母角标** `ABC` | 数字 + **小写字母角标** `abc` | 数字 + **大写字母角标** `ABC` |
| 0 | 纯数字 0 | 数字 + 角标 `空格` | 同左 | 同左 |
| # | `#`/`符号` | 同左 | 同左 | 同左 |
| 删除 | `⌫` | 同左 | 同左 | 同左 |

- **1 键 = 大小写切换**：英文模式切换后键面角标 abc↔ABC 全部翻转、候选与输出跟随；拼音模式仅改 Caps 徽章（影响后续英文片段输出）；数字模式=数字 1。
- **0 键**：数字模式=0；拼音/英文=**空格语义**——有候选：上屏高亮候选+空格；无候选：输出空格并**清空 composing**（结束当前词）。
- **# 键**：符号子面板（数字模式同样有效）。

### 3.3 符号子面板（# 唤起）

- 全屏子面板，3 列 × 4 行、每页 12 格，翻页循环：
  - 第 1 页：`.` `,` `？` `！` `：` `；` `-` `/` `@` `(` `)` `⌫`
  - 第 2 页：`"` `'` `+` `=` `*` `&` `%` `￥` `《` `》` `～` `⌫`
  - 第 3 页：`。` `，` `、` `；` `？` `！` `“` `”` `‘` `’` `—` `⌫`
- 交互同键盘区；返回键退回主面板。

## 4. 右侧候选区（五段式）

### 4.1 按键预览区（新增，候选区顶部）

显示两层信息：**按键数字串（灰，等宽）+ 预测组合行（可选中）**。

| 模式 | 预览区示例 | 组合行行为 |
|---|---|---|
| 拼音 | `64` → **ni** · mi · og(剔) | T9 音节切分的合法拼音组合（≤8 个）；**高亮组合驱动词候选刷新** |
| 英文 | `43` → **he** · if · ie · id | T9 字母组合消歧；高亮组合驱动候选词刷新；multi-tap 降级时显示当前循环字母 |
| 数字 | `已输入：123…` | 无组合行（直通模式） |
| 空 | `（未输入）` | 无 |

- 组合行左右环绕切换；**OK 在组合上 = 锁定该组合**（焦点回词行，候选保持按该组合生成）。
- 组合数超过 8 截断（概率极低，12 位 composing 多重切分时）。

### 4.2 词候选行（默认焦点层）

- 横向 6 格大字候选（28px，高 76px），高亮游标 = 焦点。
- **←→ 选词**：到行尾继续按右 = 环绕翻下一页（下一页第一个）；行首按左 = 上一页最后一个（跨页环绕，替代原"上下翻页"）。
- 每次按键刷新候选后，焦点自动重置到**当前页第 1 格**。

### 4.3 页码行

`第 x/y 页（←→ 翻页） · ↑ 拼音组合 · OK 上屏` 提示（13px 灰）。

### 4.4 预览条

- 输入框已上屏内容尾部 20 字（含语音上屏内容）。
- **密码框遮蔽**：`EditorInfo.inputType` 含 `TYPE_TEXT_VARIATION_PASSWORD/NUMBER_PASSWORD` 时，预览条显示 `●●●●`（长度对齐），**不回显明文**。

### 4.5 完成键（新增）

- 词候选行末尾固定一格 **`✓ 完成`**：执行 `performEditorAction(currentEditorAction)`（搜索/发送/完成/下一项），适配"输入完按搜索"的 TV 搜索框场景。
- 从词行尾按右即到达；OK 执行后收起面板（多数 action 语义为完成）。

### 4.6 数字模式 = 直通模式（v1.2 定稿）

数字模式**无候选、无组合行、无焦点域概念**，面板退化为纯提示层：

- 数字键 → 直接 `commitText` 上屏（不进 composing）。
- **左右键 → 移动输入框内光标**：通过 `InputConnection.setSelection()` 实现（读取 `getTextBeforeCursor/AfterCursor` 计算边界），**不透传 KeyEvent**——避免单行输入框光标到边界时 DPAD 触发焦点导航跳出输入框、连带面板关闭；到达边界时光标不动。
- 上下键：**不透传**（单行输入框透传会跳出输入框，多行场景不支持行间移动，属可接受损失）。
- 删除键 → `deleteSurroundingText(1)`；长按连删。
- 预览区显示 `已输入：…`；词行显示空态提示。
- **光标编辑路径**：拼音/英文模式需要移动光标时，按 M 切到数字模式操作，再切回（设计取舍：不为两种模式单独造光标语义，减少按键歧义）。

## 5. 交互规范

### 5.1 三层焦点模型（核心）

```
KEYPAD（键盘区）        ←→↑↓ 网格移动；最右列(3/6/9/删)按【右】→ CANDIDATE
                          ↑
CANDIDATE（词候选行）    ←→ 选词/跨页环绕；【↑】→ SYLLABLE（组合存在时）
                          ↑
SYLLABLE（组合行）      ←→ 切换组合(实时刷新词候选)；【↓】→ CANDIDATE
```

- **默认焦点**：面板弹出 = KEYPAD(5)；**有候选后 = CANDIDATE(0)**（用户规格）；composing 清空后回到 KEYPAD(5)。
- SYLLABLE 只经 CANDIDATE 的上键进入；KEYPAD 只经 CANDIDATE 的左键（行首按左）回键盘区。
  - 修正 v1.0 的域切换规则：CANDIDATE 行首按【左】 → KEYPAD（若已第 1 页第 1 格）；SYLLABLE 行首按【左】= 环绕（组合行小，环绕无歧义）。

### 5.2 按键 × 状态全表

| 按键 | KEYPAD | CANDIDATE | SYLLABLE | 数字模式（直通） |
|---|---|---|---|---|
| ←→↑↓ | 网格移动；最右列按右进词行 | ←→选词/跨页环绕；**↑进组合行**；行首按左回键盘区 | ←→切换组合；**↓回词行** | **←→移光标**（setSelection，边界不动）；↑↓ 不透传 |
| **OK** | 输入该键（§5.3） | **上屏高亮候选**，清 composing，焦点回 KEYPAD(5) | **锁定组合**，焦点回词行 | —（无动作） |
| 0-9 数字键 | **任意焦点直达**：composing += 数字 → 刷组合/候选 → 焦点落词行 | 同左 | 同左 | **直接 commitText 上屏** |
| M/MENU | 模式循环 拼音→英文→数字；清 composing | 同左 | 同左 | 同左 |
| 1 键 | 大小写切换（数字模式=1） | 同左（不抢焦点） | 同左 | —（数字模式 1 键=上屏 `1`） |
| # 键 | 符号子面板 | 同左 | 同左 | 符号子面板 |
| 0 键 | 空格语义（§3.2） | 同左 | 同左 | 直接上屏 `0` |
| 删除 | composing 非空删末位；否则 `deleteSurroundingText(1)` | 同左（删后回词行） | 同左 | `deleteSurroundingText(1)` |
| 返回 | 符号面板→关；composing 非空→清；否则**收起面板** | 同左 | 同左 | 收起面板 |
| 语音键 | 语音输入（§8），面板保持 | 同左 | 同左 | 同左 |
| ✓ 完成 | — | OK 执行 EditorAction | — | — |

### 5.3 键盘区 OK 输入语义（分模式）

| 模式 | 数字键 2-9 | 1 | 0 | # | 删除 |
|---|---|---|---|---|---|
| 拼音 | composing += 数字 → 刷组合/候选 | caps | 空格语义 | 符号面板 | 删除语义 |
| 英文 | 同上 | caps | 空格语义 | 符号面板 | 删除语义 |
| 数字 | 直接 commitText | commitText `1` | commitText `0` | 符号面板 | deleteSurroundingText |

> 数字模式下 OK 键无动作（无候选可确认，直通模式无"确认"语义）；光标移动由左右键承担（§4.6）。

### 5.4 长按

| 键 | 行为 |
|---|---|
| 删除 | 连删（首延 400ms，重复 60ms；composing 与输入框字符均适用） |
| 数字键 | 该数字**直接 commitText 上屏**（跳过 composing，任意非数字模式；输入数字的快捷路径） |
| 其它 | 无 |

### 5.5 超时与自动行为

- 英文 multi-tap 降级：1.2s 无按键锁定当前字母。
- composing 上限 12 位，超出忽略按键并闪烁预览区提示。
- 面板空闲 60s（composing 空）自动收起。
- 按键音（可选，Prefs 默认关）。

## 6. 状态机

```
Mode        = PINYIN | ENGLISH | NUMBER
Caps        = LOWER | UPPER
Focus       = KEYPAD(id) | CANDIDATE(idx,page) | SYLLABLE(idx) | SYMBOL(page,idx)
              NUMBER 模式下 Focus 无效（直通模式，方向键全部由 §4.6 语义处理）
Composing   = "" | 数字串（≤12；NUMBER 模式恒空）
Combo       = 当前选中组合（拼音切分/字母序列；NUMBER 无）
SymbolPanel = OPEN | CLOSED
Panel       = HIDDEN | SHOWN
```

- 弹出：`onStartInputView` + `FocusPolicy.hasFocus` + 设置开 → SHOWN，Focus=KEYPAD(5)；Mode/Caps 从 Prefs 恢复。
- **编辑器切换（onStartInput 换 target）**：composing/Combo 强制清空（禁止跨编辑器残留），Panel 保持或按新 inputType 重估。
- 失焦（onFinishInput）：composing 非空 → **上屏当前高亮候选**（不是原始数字串）再收起。
- 收起面板：`requestHideSelf(0)`；`onEvaluateFullscreenMode` 恒 false（TV 禁止全屏提取模式）。
- 焦点迁移规则（§5.1）+ 每次候选刷新焦点自动落 CANDIDATE(0)。

## 7. 候选引擎

### 7.1 拼音 T9 流水线

```
数字串(≤12)
  → 字母组合枚举（剪枝：仅保留合法音节前缀）
  → 音节切分（倒查 trie，剔除非法组合）→ 输出【组合列表】（预览区可选中）
  → 按选中组合查词库：整句 ngram > 词组 > 单字
  → 频率排序（静态词频 + 用户词频 Prefs Map<词,次数>）
  → LLM 重排钩子（§7.4，可选）
  → ≤36 候选（6 页）
```

- 单次查询 ≤30ms；≥8 位用增量剪枝，超预算转后台 + 50ms 去抖。
- 切换组合（SYLLABLE）仅重跑"查词库→排序"（组合列表本身不变），≤10ms。
- 词库：`assets/dict/t9_pinyin.bin`（约 10 万词 trie，+1.5MB），生成脚本 `tools/build_t9_dict.py`。

### 7.2 英文 T9

- 主路径：数字串 → 词库消歧输出【字母组合列表】→ 每个组合对应的候选词（caps 决定大小写）。
- 降级 multi-tap（无词库命中或 Prefs 选择）：同键连按循环字母，1.2s 超时/方向键锁定；预览区组合行显示当前循环字母。

### 7.3 符号与数字

直通上屏，不进引擎。

### 7.4 LLM 重排钩子（与大模型助手合流）

- 触发条件：候选 ≥6 且用户连续翻页 2 次（前两页没找到）才发起，避免每键调 API。
- Prompt：`上下文="{已上屏尾部20字}"，候选=[...]，按中文输入习惯重排，仅返回顺序 JSON`。
- 超时 800ms 静默回退；端点复用语音助手 LLM 配置；Prefs 开关默认关。

## 8. 与语音输入共存

| 场景 | 行为 |
|---|---|
| 面板显示，按住语音键 | VoiceController 正常启动，面板保持；ASR 中间结果 `setComposingText`（输入框内，覆盖九键 composing——九键 composing 非空时**先 flush 高亮候选再交出 composing**） |
| 语音进行中按九键 | 忽略 + Toast「语音输入中…」，结束自动恢复 |
| 语音结果提交 | `commitText` 追加光标处，与九键内容自然拼接 |
| 语音失败 | 面板无感 |

- 语音键沿用 `triggerKeyCodes`，与九键无键位冲突。

## 13. v1.0 → v1.1 交互遗漏修复记录

1. **按键预览区缺失** → 新增五段式右侧区（数字串 + 预测组合行，可选中切换，驱动候选）。
2. **默认焦点在键盘区** → 改为有候选后自动落候选词行（用户规格）。
3. **上下翻页与新"上键进拼音区"冲突** → 翻页并入 ←→ 跨页环绕，上下键专职域切换。
4. **composing 只在面板显示** → 改为 `setComposingText` 内联输入框（标准 IME 语义），上屏不闪断。
5. **无光标移动能力** → 数字模式左右透传移动光标（可选）；词光标编辑依赖删除键。
6. **无 EditorAction 通路**（TV 搜索框"输入完按搜索"）→ 词行末尾「✓ 完成」格执行 performEditorAction。
7. **密码框明文回显风险** → 预览条对 password inputType 遮蔽。
8. **编辑器切换 composing 残留** → onStartInput 换 target 强制清空。
9. **失焦丢字风险** → 失焦自动上屏高亮候选（而非原始数字串）。
10. **TV 全屏提取模式** → `onEvaluateFullscreenMode` 恒 false。
11. **面板遮挡输入框** → 依赖 adjustResize；实测不可见时降面板高度（验收 19）。
12. **唤起机制含糊** → 明确双路径 + 实测项（§12-1）。
13. **multi-tap 降级在预览区无反馈** → 组合行显示当前循环字母。
14. **0 键空格后 composing 残留** → 明确清空（结束当前词）。
15. **按键反馈缺失** → 可选按键音（默认关）。
16. **数字模式缺光标编辑**（v1.2）→ 数字模式定为直通模式：数字直接上屏、左右键 `setSelection` 移光标（边界不动、不丢焦点）、上下不透传；拼音/英文移动光标需先切数字模式。
